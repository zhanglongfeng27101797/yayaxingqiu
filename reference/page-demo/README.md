# 芽芽星球工作台｜页面 Demo

这是给公司研发同事看的**纯页面结构 Demo**。

- 不使用 Flutter / Taro / uni-app / 小程序框架；
- 只是一个可直接用浏览器打开的静态 HTML；
- 用于理解页面层级、卡片密度、Tab 顺序、信息优先级；
- 不代表技术实现方式；
- 不代表其中按钮都是真实功能。

## 打开方式

直接打开：

`reference/page-demo/index.html`

## Demo 已按当前需求修正

- TabBar：**首页｜创作｜对标｜成长｜我的**
- 对标第 3
- 成长倒数第二
- 首页高识别工具：采集爆款 / 视频拆解 / 去水印 / 提词器
- 成长主标题：芽芽星球商学苑
- 我的页有“我的创作”统一稿件入口
- 不出现运营老师 / 陪跑老师 / 阿欣老师
- 不出现“万人想拍”
