# 芽芽星球工作台｜页面 Demo

这是一个**纯页面结构 Demo**。

- 不绑定 Flutter / Taro / uni-app / 小程序框架；
- 可直接用浏览器打开静态 HTML；
- 用于展示页面层级、卡片密度、Tab 顺序和信息优先级；
- 不代表正式技术实现；
- 不代表其中所有按钮已经具备真实业务能力。

## 打开方式

直接打开：

`reference/page-demo/index.html`

## 当前页面结构

- TabBar：**首页｜创作｜对标｜成长｜我的**
- 对标第 3
- 成长倒数第二
- 首页高识别工具：采集爆款 / 视频拆解 / 去水印 / 提词器
- 成长主标题：芽芽星球商学苑
- 我的页包含“我的创作”统一稿件入口
- 不出现运营老师 / 陪跑老师 / 阿欣老师
- 不出现“万人想拍”等无真实来源数据
