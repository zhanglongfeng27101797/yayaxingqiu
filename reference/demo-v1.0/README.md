# 历史 Demo V1.0｜仅供视觉与交互参考

> ⚠️ **禁止把本目录当成正式开发基线。** 正式产品是微信小程序，产品与研发真源在 `docs/`；正式前端目录是 `apps/miniprogram/`。

本目录来自产品负责人曾在安卓手机上体验的 `芽芽星球工作台-demo-v1.0.apk`。APK 本质为 Android WebView 包装的 HTML/CSS/JavaScript Demo，本目录保留其可读前端资源，方便前端理解早期页面气质、卡片密度和交互意图。

## 可以参考什么

- 整体温和、轻量的视觉气质；
- 首页“今天值得拍”“继续创作”等模块的基本卡片形态；
- 选题 → 创作设置 → 脚本 → 提词器的早期交互尝试；
- 对标列表与详情的早期信息组织；
- 一些文案和 Demo 示例数据。

## 明确不能照搬什么

历史 Demo 已确认存在以下偏差/缺陷，**不得复制到正式小程序**：

1. 底部导航旧顺序曾为：首页｜创作｜成长｜对标｜我的；正式顺序必须是 **首页｜创作｜对标｜成长｜我的**。
2. “提取逐字稿”等部分按钮只是占位 Toast，不代表正式需求允许假交互。
3. 首页“视频拆解”曾直接跳对标库；正式版必须是独立分析入口。
4. “换一组开头”曾只是把原 3 句换顺序；正式版必须返回新的 3 个开头。
5. 脚本生成曾大量套固定正文，方向/口吻没有真实改变结果；正式版必须按 **源内容 × 方向 × 开头 × 口吻** 生成。
6. 历史草稿存在跨题 fallback/串稿风险；正式版禁止读取其他稿件兜底。
7. 提词器旧 Demo 的速度不可真实调整；正式版需慢/中/快三档。
8. 旧采集记录使用固定 ID，连续采集可能覆盖；正式版每次正常采集需独立 ID。
9. “我的采集”旧筛选会混入历史采集内容；正式版只允许 `user_capture`。
10. 爆款详情旧版缺少完整逐字稿模块；正式版必须有节选与展开全文。
11. 成长页旧版偏课程列表；正式版是“芽芽星球商学苑”，包含课程、分享、直播回放、运营精选、平台规则等。
12. 历史 Demo 是 Android/WebView 形态，不包含微信小程序生命周期、登录、合法域名、隐私审核等正式工程要求。

- `legacy-webview/index.html`：旧 WebView 页面容器；
