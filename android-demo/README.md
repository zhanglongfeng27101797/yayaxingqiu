# 芽芽星球工作台 Android Demo

这是一个纯本地、可安装的产品演示版。所有采集、生成、保存、课程和消息操作都使用本地状态模拟，不会访问真实抖音、AI 或飞书接口。

核心可点击链路：

- 今日选题 → 方向 / 真实换组三开头 / 口吻 → 脚本编辑与撤销 → 三档提词器。
- 采集爆款 → 本地模拟采集 → 拆解 → 变成我的版本。
- 独立的逐字稿和视频拆解流程、来源筛选、成长搜索和个人资料持久化。
- 底部导航固定为：首页、创作、对标、成长、我的。

「对标爆款库」中的产后护理、孕期饮食和孕期生活条目取自原育咖采集表的只读快照；交互数据不是实时值，页面已显式标注为演示数据。

构建命令：

```bash
./build-apk.sh
```

输出位置：`app/outputs/apk/debug/芽芽星球工作台-demo-v1.2.apk`。
