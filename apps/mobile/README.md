# ⚠️ 历史 Flutter 原型｜禁止继续作为正式前端开发

本目录是早期 Codex 生成的 Flutter/Dart 移动端工程骨架，**不是芽芽星球正式产品代码**。

正式产品已经冻结为：**微信小程序**。

正式前端请进入：`apps/miniprogram/`。

## 本目录允许用途

- 查看早期五入口和页面结构尝试；
- 对照历史产品迭代；
- 必要时参考少量业务命名。

## 本目录禁止用途

- 不得继续新增正式业务；
- 不得以 Flutter 生命周期/存储/导航方式指导小程序实现；
- 不得以本目录页面覆盖 `docs/product/page-specification.md`；
- 不得将 Android/iOS 构建作为 V1 交付目标；
- 不得因为此目录存在而认为产品仍需独立 App。

任何冲突均以 `docs/delivery/source-and-decisions.md` 与当前小程序文档为准。
