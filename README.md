# 芽芽星球工作台

**芽芽星球工作台**是给公司签约宝妈创作者使用的微信小程序创作助手。

它要帮助用户完成：

**今天拍什么 → 找/采集对标 → 看懂爆款 → 变成自己的版本 → 生成脚本 → 提词拍摄 → 学习提升。**

## 最重要的产品边界

- 正式产品是**微信小程序**。
- 产品是创作助手 / 工作台，不是陪跑服务。
- 不出现专属运营老师、陪跑老师、联系运营、阿欣老师等入口。
- 成长页主标题是**芽芽星球商学苑**，不是作业 / 评级中心，也不只是课程商城。
- “我的创作”是统一稿件资产库，首页生成、选题生成、对标二创都沉淀到同一份稿件库。
- V1 提词器只在小程序内使用，不做跨 App 悬浮、相机、美颜、滤镜和剪辑。
- 旧 Flutter / APK / WebView Demo 都不能反向覆盖当前产品需求。
