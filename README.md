# 芽芽星球工作台

**芽芽星球工作台**是面向公司签约宝妈创作者的微信小程序创作助手。

核心目标：

**今天拍什么 → 找/采集对标 → 看懂爆款 → 变成自己的版本 → 生成脚本 → 提词拍摄 → 学习提升。**

## 产品形态

正式产品：**微信小程序**

固定底部导航：

**首页｜创作｜对标｜成长｜我的**

- 首页：今天值得拍、创作简报、常用工具、继续创作、商学苑推荐
- 创作：选题、方向、开头、口吻、脚本编辑、我的创作、提词器
- 对标：采集爆款、我的采集、芽芽精选、爆款拆解、逐字稿、二创
- 成长：芽芽星球商学苑，承载课程、分享、回放、运营精选、平台规则、带货经验等
- 我的：账号、创作资料、我的创作、权益、消息、帮助、设置

## 关键产品边界

- 产品是创作助手 / 工作台，不是陪跑服务平台。
- 不出现专属运营老师、陪跑老师、联系运营、阿欣老师等入口。
- 成长页主标题为**芽芽星球商学苑**，不做作业、打卡、积分、排行榜和强制评级。
- “我的创作”是统一稿件资产库，首页生成、选题生成、对标二创都沉淀到同一份稿件库。
- V1 提词器只做小程序内基础提词，不做跨 App 悬浮、相机、美颜、滤镜和剪辑。
- 页面 Demo 中的业务数据均应明确标识为示例数据或历史快照。
