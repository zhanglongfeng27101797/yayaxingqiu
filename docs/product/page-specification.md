# 完整页面规格｜微信小程序 V1

> 用于前端直接理解：每一页有什么、怎么排、点哪里、跳哪里。
>
> 技术实现方式由研发自行决定。

---

# 0. 全局规则

## 0.1 TabBar

固定顺序：

**首页｜创作｜对标｜成长｜我的**

- 对标第 3 位
- 成长第 4 位（倒数第二）
- 我的最后

## 0.2 页面体验原则

- 70% 温和陪伴感 + 30% 专业工作台感
- 首页优先回答“我现在该干什么”，不是展示工具数量
- 主 CTA 明确，次级动作弱化
- 主流程按钮必须真实可用，不用 Toast 冒充完成
- Demo 业务数据统一标“演示版·示例数据”
- 历史数据标来源和采集时间
- 用户端不出现陪跑老师、专属运营、联系运营、阿欣老师、作业、签到、积分、评级
- 正式工具图标统一醒目，避免大量 Emoji
- 禁止“万人想拍”“XX 人正在拍”等无真实来源数据

# HOME-01 首页

## 目标

让用户打开小程序后 3–5 秒内知道：

- 今天有什么值得拍
- 刚刷到的爆款怎么采集
- 未完成的稿子怎么继续

## 页面顺序

### A. 顶部问候

- “晚上好，小雨妈妈”一类轻问候
- 芽芽一句轻提示
- 不出现客服 / 运营 / 陪跑老师入口

### B. 今天值得拍｜主卡

主推荐 1 条：

- 标题
- 星级
- 为什么推荐给你
- 2–3 个标签
- 拍摄难度
- 【我想拍】

主卡下面再放 2 条轻量推荐。

交互：

- 点主卡 → TOPIC-DETAIL-01
- 点【我想拍】 → CREATE-CONFIG-01
- 点另外两条 → 对应选题详情

### C. 本月创作简报

显示：

- 本月发布数
- 本月累计点赞
- 连续创作天数

正式数据拿不到时：隐藏 / 暂无 / 待绑定；不要伪造实时数据。

### D. 常用工具

首页不放永久链接输入框，点击工具后再输入。

#### 首页视觉优先顺序

1. 采集爆款
2. 视频拆解（拆视频）
3. 去水印
4. 提词器

同时保留：

- 提取逐字稿
- 灵感库

#### 采集爆款

主工具，视觉权重最高。

文案可类似：

**采集一个刚刚刷到的爆款**

“粘贴视频链接，保存到你的对标库并开始拆解”

【粘贴链接采集】 → CAPTURE-01

#### 视频拆解

→ ANALYZE-01

#### 去水印

若真实能力暂未开放，可标“暂未开放 / 建设中”，但保留入口需求。

#### 提词器

→ TELEPROMPTER-01，优先读取最近草稿。

#### 提取逐字稿

→ TRANSCRIPT-01

#### 灵感库

保留入口，后续完善。

### E. 继续创作

展示最近 1–3 条：

- 标题
- 来源
- 更新时间
- 【继续编辑】
- 【去提词】

### F. 商学苑推荐

推荐 1 条课程 / 分享 / 回放 / 运营精选等内容。

# CREATION-01 创作首页

## 目标

集中完成：找选题 → 配置 → 写稿，并可进入统一“我的创作”。

## 页面结构

1. 搜索框（如果展示，就必须真实可用；阶段内不做可先不展示）
2. 推荐选题列表
3. 基础筛选入口
4. 【我的创作】入口

“我的创作”和“我的”页里的入口必须指向同一份稿件库。

## 选题卡最低信息

- 标题
- 星级
- 内容类型
- 推荐理由一句
- 难度
- 医疗风险标识（如适用）

点击 → TOPIC-DETAIL-01

---

# TOPIC-DETAIL-01 选题详情

## 页面结构

1. 标题 + 星级
2. 为什么推荐
3. 内容类型 / 标签
4. 指标：
   - 宝妈可创作性
   - 创作空间
   - 拍摄难度
   - 内容拥挤度
   - 医疗风险
   - 平台风险
5. 拍摄建议
6. 【我想拍】

不同选题的指标要有差异，不能全部固定一样。

## 三星选题

如果为“★★★☆☆ 可以改”：

提示：

“这个题有需求，但普通宝妈直接讲容易太专业 / 太泛。”

按钮：

【帮我改成适合宝妈拍】

点击后给 3 个切口：

- 我的真实经历
- 我当时最想知道的问题
- 一个具体生活场景

选择后 → CREATE-CONFIG-01

---

# CREATE-CONFIG-01 创作设置

## Step 1｜这条想怎么讲

显示 3 个方向：

- 推荐 1 个
- 备选 2 个

方向库：

- 判断解惑
- 避坑纠错
- 流程清单
- 对比选择
- 经验复盘
- 好物种草

如果展示【查看更多方式】，必须真的展开更多方向；否则删除。

## Step 2｜你更喜欢哪个开头

一次显示 3 个开头 A / B / C。

按钮：【换一组】

点击后必须出现新的 D / E / F，不允许只是改变排序。

## Step 3｜你想怎么说

四个口吻：

- 自然聊天
- 真实经验
- 清楚专业
- 有点冲突

## 底部主按钮

【生成我的版本】

生成结果必须真实受到：

**当前源内容 + 方向 + 选中的开头 + 口吻**影响。

成功 → SCRIPT-EDITOR-01

---

# SCRIPT-EDITOR-01 脚本编辑

## 页面结构

- 标题
- 开头
- 正文
- 结尾
- 拍摄建议

所有文本区允许编辑。

## 快速优化

- 更口语
- 再短一点
- 更抓人

操作后建议显示【撤销】。

## 换个开头

点击后弹出 3 个新开头供选择；用户确认后才替换，不直接覆盖。

## 底部操作

- 自动保存状态
- 【去提词】

禁止：当前稿件缺字段时读取另一条稿件正文兜底。

所有来源生成的稿件最终统一进入“我的创作”。

# MY-CREATIONS-01 我的创作

## 定位

统一稿件 / 草稿资产库，不是另一套创作系统。

统一收纳：

- 首页推荐生成稿
- 创作选题生成稿
- 对标二创稿
- 后续自定义选题稿

入口：

- 创作页
- 我的页

两个入口看到同一份数据。

每条至少支持：

- 继续编辑
- 去提词

---

# TELEPROMPTER-01 小程序内提词器

## 功能

- 开始 / 暂停
- 字号调整
- 速度：慢 / 中 / 快
- 镜像开关
- 重置

切换速度后必须真实影响滚动。

## V1 边界

不做：

- 跨 App 悬浮
- 相机替代
- 美颜
- 滤镜
- 剪辑

---

# CAPTURE-01 采集爆款

## 入口

- 首页主工具
- 对标页顶部

## 页面 / 弹层

1. 链接输入框
2. 【开始采集】
3. 处理状态
4. 成功结果

成功结果至少显示：

- 标题
- 作者
- 来源
- 封面（若有）
- 【查看拆解】
- 【留在我的采集】

连续采集多条必须全部保留，不能后一条覆盖前一条。

# BENCHMARK-01 对标

## 页面结构

### 顶部采集入口

明显，但不占用过多高度。

### Tab / 筛选

- 全部
- 我的采集
- 芽芽精选

来源规则：

- 我的采集 = 用户自己粘贴链接采集
- 芽芽精选 = 公司 / 运营精选
- 历史迁移内容只在“全部”出现，并标明历史来源

### 卡片

要求一屏尽量多条。

包含：

- 封面
- 星级 / 推荐等级
- 标题
- 内容类型
- 播放（能获得时）
- 点赞
- 收藏
- 评论
- 来源
- 1–2 个“值得学”标签
- 拆解入口

禁止伪精确匹配度、来源不明的“XX 人想拍”。

点击 → BENCHMARK-DETAIL-01

---

# BENCHMARK-DETAIL-01 爆款拆解详情

## 页面顺序

1. 封面 / 标题 / 作者 / 数据 / 星级
2. 一句话看懂
3. 为什么值得学
4. 开头为什么抓人
5. 内容结构
6. 最值得学的 3 个地方
7. 逐字稿节选
8. 【展开全文】
9. 二创提醒
10. 【变成我的版本】

【变成我的版本】 → CREATE-CONFIG-01，继续走方向 / 开头 / 口吻，不做黑盒一键改写。

# TRANSCRIPT-01 提取逐字稿

## 流程

1. 粘贴链接
2. 【开始提取】
3. 显示处理状态
4. 成功展示标题、作者、逐字稿
5. 操作：
   - 复制全文
   - 保存
   - 去拆解

# ANALYZE-01 视频拆解

## 入口方式

- 粘贴链接
- 从“我的采集”选择

成功后 → BENCHMARK-DETAIL-01

视频拆解是独立分析动作，不等同于“打开对标库”。

# GROWTH-01 成长｜芽芽星球商学苑

## 位置

TabBar 第 4 位，倒数第二。

## 页面结构

### A. 你现在最想解决什么

五个问题全部可见，可自动换行：

- 不知道拍什么
- 不会写脚本
- 不会拍视频
- 流量起不来
- 想开始带货

### B. 为你推荐

只推荐 1 条，根据问题动态变化。

内容类型不限课程，可包括：

- 课程
- 直播回放
- 分享
- 运营精选
- 平台规则
- 爆款复盘
- 带货经验
- 工具教程

### C. 系统课程

正式课程列表。

### D. 本周分享 / 直播回放

内部分享和回放。

### E. 运营精选

爆款复盘、平台观察、实操经验。

### F. 最新内容

平台规则、商务带货、工具教程等。

## 用户阶段

可以根据用户资料做轻量推荐，但不向用户展示强制 Level / 阶段评级。

## 明确禁止

- 作业
- 打卡 / 签到
- 积分
- 排行榜
- Level 评级
- 专属运营老师
- 陪跑老师
- 联系运营

# PROFILE-01 我的

## 页面结构

1. 用户基本信息
2. 【我的创作】入口 → MY-CREATIONS-01
3. 账号管理 / 添加账号
4. 创作资料
5. 我的权益
6. 消息与通知
7. 帮助与反馈
8. 设置
9. 关于

## 创作资料

至少可编辑：

- 昵称
- 创作方向
- 宝宝年龄
- 表达风格
- 是否愿意露脸

保存后真实回写。

## 账号管理边界

V1 先做基础账号信息 / 添加入口即可，不等于必须接抖音深度 OAuth、创作中心深层指标。

用户端不显示：

- 项目负责人：隆隆老师
- 阿欣老师
- 运营 / 陪跑老师服务入口

---

# 全局状态原则

核心页面至少考虑：

- 加载中
- 正常内容
- 空状态
- 失败 / 重试

编辑类页面：

- 编辑中
- 保存中
- 已保存
- 保存失败

不要为了展示状态而把复杂技术术语暴露给普通用户。

---

# 核心验收红线

1. 用户能从“今天值得拍”一路生成正确脚本并进入提词器。
2. 用户能连续采集 3 条，全部保留在“我的采集”。
3. 对标详情必须有逐字稿节选 / 全文。
4. 方向、开头、口吻必须真实改变脚本结果。
5. 成长页不能做成单纯课程商城或作业中心。
6. 小程序端不得出现陪跑老师 / 运营老师服务入口。
7. “我的创作”必须是一份统一稿件库，可从创作页和我的页进入。
8. 首页常用工具视觉优先关系不得做乱。
