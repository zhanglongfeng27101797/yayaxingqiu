# 完整页面规格｜微信小程序 V1

> 本文用于前端直接实现页面与交互。页面顺序、模块权重、按钮行为、状态和跳转以本文为准。

## 0. 全局规则

### 0.1 TabBar

固定顺序：**首页｜创作｜对标｜成长｜我的**。

### 0.2 页面体验原则

- 70% 温和陪伴感 + 30% 专业工作台感。
- 不把首页做成工具箱堆叠；优先回答“我现在该干什么”。
- 核心 CTA 使用明确主按钮；次级动作弱化。
- 主流程按钮必须真实可用，不能用 Toast 冒充完成。
- 业务数据若为演示/历史快照，必须明确标识来源与采集时间。
- 用户端不出现陪跑老师、专属运营、联系运营、作业、签到、积分、评级。

# HOME-01 首页

## 目标

让用户打开小程序后 3–5 秒内知道：今天有什么值得拍、刚刷到的爆款怎么采集、未完成的稿子怎么继续。

## 页面顺序（自上而下）

### A. 顶部问候

内容：

- “晚上好，小雨妈妈”一类轻问候；
- 芽芽一句轻陪伴提示；
- 不出现客服/陪跑老师入口。

### B. 今天值得拍｜主卡

主推荐 1 条：

- 标题
- 星级（5 星体系）
- 为什么推荐给你
- 2–3 个标签
- 拍摄难度
- 主按钮【我想拍】

主卡下方展示另外 2 条适合用户的选题，信息更轻。

交互：

- 点主卡 → TOPIC-DETAIL-01
- 点【我想拍】 → CREATE-CONFIG-01
- 点另外两条 → 对应选题详情

状态：loading / success / empty / error。

### C. 本月创作简报

显示：

- 本月发布数
- 本月累计点赞
- 连续创作天数

若正式数据暂不可获得：不伪造实时数据；允许隐藏该模块或标注“演示数据 / 待绑定”。

### D. 常用工具

#### 主工具卡：采集爆款

视觉权重最高。

文案示例：

**采集一个刚刚刷到的爆款**

“粘贴视频链接，保存到你的对标库并开始拆解”

【粘贴链接采集】

点击 → CAPTURE-01。

#### 次级工具

- 提取逐字稿 → TRANSCRIPT-01
- 视频拆解 → ANALYZE-01
- 提词器 → TELEPROMPTER-01（优先读取最近草稿）
- 去水印 → V1 若未实现明确“暂未开放”
- 灵感库 → V1 若未实现明确“暂未开放”

### E. 继续创作

展示最近 1–3 条草稿：

- 标题
- 来源（热点/对标二创/手动）
- 更新时间
- 【继续编辑】
- 【去提词】

### F. 商学苑推荐

根据当前问题推荐 1 条学习内容，展示 contentType。

点击 → GROWTH-DETAIL-01。

# CREATION-01 创作首页

## 目标

给用户一个集中找选题和管理“我的创作”的入口。

## 页面结构

1. 搜索框（V1 保留则必须实际过滤）
2. 推荐选题列表
3. 筛选：内容类型 / 难度 / 风险（复杂筛选可后置）
4. 我的创作入口

## 选题卡最低信息

- 标题
- 星级
- 内容类型
- 推荐理由一句
- 难度
- 医疗风险标识（如适用）

点击 → TOPIC-DETAIL-01。

---

# TOPIC-DETAIL-01 选题详情

## 页面结构

1. 标题 + 星级
2. 为什么推荐
3. 内容类型 / 标签
4. 指标：
   - 宝妈可创作性
   - 创作空间
   - 拍摄难度
   - 内容拥挤度
   - 医疗风险
   - 平台风险
5. 拍摄建议
6. 主按钮【我想拍】

## 三星选题

若为“★★★☆☆ 可以改”：

显示提示：

“这个题有需求，但普通宝妈直接讲容易太专业/太泛。”

显示按钮【帮我改成适合宝妈拍】。

点击后给 3 个切口：

- 我的真实经历
- 我当时最想知道的问题
- 一个具体生活场景

选择后进入 CREATE-CONFIG-01。

# CREATE-CONFIG-01 创作设置

## Step 1｜这条想怎么讲

显示 3 个方向：

- 推荐 1 个
- 备选 2 个

方向库：

- 判断解惑
- 避坑纠错
- 流程清单
- 对比选择
- 经验复盘
- 好物种草

“查看更多方式”如果展示，必须真的展开更多方向；否则删除。

## Step 2｜你更喜欢哪个开头

显示 3 个开头 A/B/C。

按钮【换一组】。

要求：点击后必须出现新的 D/E/F，不允许只改变排序。

## Step 3｜你想怎么说

四个口吻：

- 自然聊天
- 真实经验
- 清楚专业
- 有点冲突

## 底部主按钮

【生成我的版本】

请求参数至少包含：sourceType、sourceId、direction、hook、tone。

成功 → SCRIPT-EDITOR-01。

# SCRIPT-EDITOR-01 脚本编辑

## 页面结构

- 标题
- 开头
- 正文
- 结尾
- 拍摄建议

所有文本区允许编辑。

## 快速优化

- 更口语
- 再短一点
- 更抓人

操作后显示【撤销】。

## 换个开头

点击后弹出 3 个新开头供选择；用户确认后才替换。

## 底部操作

- 自动保存状态
- 【去提词】

禁止：当前草稿字段缺失时读取另一条草稿正文兜底。

---

# TELEPROMPTER-01 小程序内提词器

## 功能

- 开始 / 暂停
- 字号调整
- 速度：慢 / 中 / 快
- 镜像开关
- 重置

速度切换在滚动中即时生效。

## V1 边界

不做跨 App 悬浮、不做相机替代、不做美颜滤镜和剪辑。

# CAPTURE-01 采集爆款

## 入口

首页主工具卡、对标页顶部。

## 页面/弹层

1. 链接输入框
2. 【开始采集】
3. 处理状态
4. 成功结果

成功结果至少显示：

- 标题
- 作者
- 来源
- 封面（若有）
- 【查看拆解】
- 【留在我的采集】

每次正常采集创建唯一 ID。

# BENCHMARK-01 对标

## 页面结构

### 顶部采集入口

明显但不占用过多高度。

### Tab/筛选

- 全部
- 我的采集
- 芽芽精选

来源规则：

- 我的采集 = user_capture
- 芽芽精选 = yaya_pick
- legacy_snapshot 只在全部中出现

### 卡片

一屏尽量多条，包含：

- 封面
- 星级
- 标题
- 内容类型
- 点赞 / 收藏 / 评论 / 播放
- 来源
- 1–2 个“值得学”标签

点击 → BENCHMARK-DETAIL-01。

---

# BENCHMARK-DETAIL-01 爆款拆解详情

## 页面顺序

1. 封面 / 标题 / 作者 / 数据 / 星级
2. 一句话看懂
3. 为什么值得学
4. 开头为什么抓人
5. 内容结构
6. 最值得学的 3 个地方
7. 逐字稿节选
8. 【展开全文】
9. 二创提醒
10. 主按钮【变成我的版本】

【变成我的版本】 → CREATE-CONFIG-01，并携带 benchmark source。

---

# TRANSCRIPT-01 提取逐字稿

## 流程

1. 粘贴链接
2. 【开始提取】
3. 显示 queued/processing 状态
4. 成功展示标题、作者、逐字稿
5. 操作：
   - 复制全文
   - 保存
   - 去拆解

用户离开页面后任务继续服务端执行；再次进入恢复状态。

---

# ANALYZE-01 视频拆解

## 入口方式

- 粘贴链接
- 从“我的采集”选择

成功后进入 BENCHMARK-DETAIL-01。

视频拆解不等同于“打开对标库”。

# GROWTH-01 成长｜芽芽星球商学苑

## 位置

TabBar 第 4 位，倒数第二。

## 页面结构

### A. 你现在最想解决什么

五个问题全部可见，可自动换行：

- 不知道拍什么
- 不会写脚本
- 不会拍视频
- 流量起不来
- 想开始带货

### B. 为你推荐

只推荐 1 条，根据问题动态变化。

内容类型不限定课程，可以是：课程 / 直播回放 / 分享 / 运营精选。

### C. 系统课程

正式课程列表。

### D. 本周分享 / 直播回放

内部分享和回放。

### E. 运营精选

爆款复盘、平台观察、实操经验。

### F. 最新内容

平台规则、商务带货、工具教程等。

## 明确禁止

- 作业
- 签到
- 积分
- 排行榜
- Level 评级
- 专属运营老师
- 陪跑老师

# PROFILE-01 我的

## 页面结构

1. 用户基本信息
2. 账号绑定
3. 创作资料
4. 我的权益
5. 消息与通知
6. 帮助与反馈
7. 设置
8. 关于

## 创作资料

至少可编辑：

- 昵称
- 创作方向
- 宝宝年龄
- 表达风格

# 全局状态矩阵

| 场景 | 必须状态 |
| --- | --- |
| 普通远程列表 | loading / success / empty / offline / error |
| 异步任务 | queued / processing / retriable_failed / failed / cancelled / succeeded |
| 表单编辑 | pristine / dirty / saving / saved / save_failed |
| 脚本生成 | idle / generating / success / error |
| 搜索 | idle / typing / result / no_result / error |

# 核心验收红线

1. 用户能从“今天值得拍”一路生成正确脚本并进入提词器。
2. 用户能连续采集 3 条，全部保留在“我的采集”。
3. 对标详情必须有逐字稿节选/全文。
4. 方向、开头、口吻必须真实改变脚本结果。
5. 成长页不能被做成课程商城或作业中心。
6. 小程序端不得出现陪跑老师/运营老师服务入口。
