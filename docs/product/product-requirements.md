# 产品需求｜微信小程序 V1

## 1. 产品定位

芽芽星球工作台是服务公司签约宝妈创作者的 **微信小程序创作工作台**，帮助用户找到值得拍的内容、看懂对标内容、生成符合本人经历和口吻的脚本，并完成拍摄准备与学习提升。

产品不是陪跑服务平台，不提供“专属运营老师 / 陪跑老师 / 联系运营”等服务心智。

## 2. 正式平台

- 正式产品平台：**微信小程序**。
- 旧 Android APK / Flutter 工程：只作为历史 Demo、交互参考和需求材料，不作为正式前端技术路线。
- V1 提词器只做 **小程序内基础提词器**，不做跨 App 悬浮窗、不做系统相机替代、不做滤镜/美颜/剪辑。

## 3. 用户目标

- 快速找到适合自己阶段、方向和表达能力的选题。
- 把平台内容沉淀为可搜索、可追溯、可二创的对标资产。
- 看懂内容的钩子、结构、学习点、逐字稿和风险。
- 通过“系统推荐 + 少量选择”生成与本人经历和口吻匹配的脚本。
- 在编辑、换开头、撤销和提词之间连续工作。
- 针对创作问题获得课程、案例、直播回放、运营精选、平台规则等内容。

## 4. 固定底部导航

**首页｜创作｜对标｜成长｜我的**

| 模块 | 用户心智 | 核心能力 |
| --- | --- | --- |
| 首页 | 我现在该干什么 | 今日选题、采集爆款主入口、创作简报、常用工具、继续创作、商学苑推荐 |
| 创作 | 我要把一条内容做出来 | 选题、方向、开头、口吻、脚本编辑、提词器 |
| 对标 | 我要找爆款、研究别人 | 采集任务、来源筛选、结构拆解、逐字稿、转创作 |
| 成长 | 我要解决当前能力问题 | 问题标签、搜索、课程、分享、直播回放、运营精选、平台规则 |
| 我的 | 我的账号和创作资料 | 创作者资料、平台账号、权益、消息、隐私和设置 |

> 成长位于倒数第二，对标位于第三。不得再使用旧顺序。

## 5. 三条核心业务闭环

### A. 今天不知道拍什么

首页今天值得拍 → 选题详情 → 我想拍 → 选择内容方向 → 选择 3 个开头之一 → 选择口吻 → 生成脚本 → 编辑 / 优化 → 去提词。

### B. 刷到一个爆款

首页采集爆款 / 对标粘贴链接 → 创建采集任务 → 我的采集 → 拆解详情 → 查看逐字稿 → 变成我的版本 → 方向 / 开头 / 口吻 → 生成脚本 → 我的创作。

### C. 我想学习

成长 → 芽芽星球商学苑 → 选择当前问题 → 推荐内容变化 → 课程 / 分享 / 回放 / 运营精选 → 返回创作。

## 6. 首页规则

### 6.1 今天值得拍

- 首页首屏核心内容之一。
- 主推荐 1 条，附星级、推荐理由、内容标签、拍摄难度和“我想拍”。
- 同区展示另外 2 条适合用户的选题。
- 推荐理由优先体现“为什么适合这个用户”，不是公共榜单语气。

### 6.2 采集爆款

- 常用工具中的最高优先级入口。
- 点击后弹出链接输入，不在首页长期占用输入框。
- 采集成功后可进入“我的采集”或直接进入拆解。

### 6.3 常用工具优先级

P0：采集爆款、提取逐字稿、视频拆解、提词器。

P2：去水印、灵感库。若本轮未实现，必须明确“V1 暂未开放”，不能伪装为完整功能。

## 7. 创作规则

### 7.1 三步选择式创作

1. **这条想怎么讲**：推荐 1 个 + 备选 2 个方向；
2. **你更喜欢哪个开头**：一次 3 个开头，可“换一组”；
3. **你想怎么说**：自然聊天 / 真实经验 / 清楚专业 / 有点冲突。

### 7.2 生成真实性

最终脚本必须满足：

**源内容（讲什么） × 内容方向（怎么组织） × 表达口吻（怎么说） = 最终稿**

- 草稿必须绑定 `sourceType + sourceId`，生成只读取当前来源。
- 缺字段时返回明确错误，禁止读取其他选题或对标内容兜底。
- “换一组开头”每次返回三个新选项，不允许只是重排旧三句。
- “换个开头”先展示 3 个新开头，用户选择后再替换，并支持单步撤销。
- 三星选题不直接淘汰，至少提供“帮我改成适合宝妈拍”的轻量改造入口。

## 8. 对标规则

- 来源分为：`user_capture`、`yaya_pick`、`legacy_snapshot`。
- “我的采集”只展示 `user_capture`。
- “芽芽精选”只展示 `yaya_pick`。
- 历史迁移内容只在全部列表中保留来源标签，不得混入“我的采集”。
- 每次正常采集生成独立 ID；相同幂等键的重放请求返回原资源。
- 对标卡至少展示：封面、标题、星级、内容类型、点赞/收藏/评论/播放、来源。
- 拆解详情包含：一句话看懂、为什么值得学、开头分析、内容结构、学习点、逐字稿节选/全文、二创提醒、变成我的版本。

## 9. 成长规则

主标题固定为 **芽芽星球商学苑**。

成长页不是课程商城，也不是作业/考核中心。内容类型包括：

- 系统课程
- 内部分享
- 直播回放
- 运营精选
- 爆款复盘
- 平台规则
- 带货经验
- 工具教程

当前问题至少包括：不知道拍什么、不会写脚本、不会拍视频、流量起不来、想开始带货。

明确禁止：阶段评级、作业、签到、积分、排行榜、专属运营老师、陪跑老师、陪跑服务入口。

## 10. 我的规则

- 保留：账号绑定、创作资料、权益、消息与通知、帮助反馈、设置、关于。
- 创作资料至少包含：昵称、创作方向、宝宝年龄、表达风格、是否愿意露脸。
- 用户修改后必须真实保存并跨页面一致。
- 用户端不显示“项目负责人：隆隆老师”等内部项目说明，也不把负责人包装成陪跑/客服入口。

## 11. 提词器规则

V1 小程序内提词器必须包含：

- 开始 / 暂停
- 字号调整
- 慢 / 中 / 快三档速度
- 重置
- 镜像（可选开关）

不做跨 App 悬浮提词，不做相机、美颜、滤镜、剪辑。

## 12. 正式数据与服务

- PostgreSQL 是业务数据真源。
- 对象存储保存媒体、封面、原始快照和大文本。
- 采集、转写和分析通过队列与 Worker 异步执行。
- 飞书只作为运营导入导出和后台兼容渠道。
- Prompt、模型、逐字稿和分析结果全部版本化。
- 指标必须带采集时间，不得把历史指标表达为实时值。

## 13. 微信小程序技术与体验边界

- 登录采用 `wx.login` 获取临时 code，服务端换取微信身份并建立业务会话。
- 前端不得持有 `AppSecret` 等服务端密钥。
- 网络请求只访问微信小程序已配置并备案/合规的 HTTPS 合法域名。
- 长耗时采集、ASR、分析不得依赖小程序前台常驻；统一创建异步任务并支持重新进入后恢复状态。
- 本地只缓存轻量草稿、筛选条件和非敏感状态；正式业务真值以服务端为准。
- 图片/视频上传使用小程序上传能力或后端签名上传方案；媒体链接按权限和有效期控制。
- 页面设计按微信小程序安全区、胶囊按钮、底部 TabBar 和常见 375px 设计宽度适配。

## 14. 内容安全

- 医疗高风险选题只允许记录、观察、经验边界与就医沟通框架，不提供诊断、剂量和具体用药建议。
- AI 生成、对标拆解与逐字稿结果均需要内容安全策略与必要的风险提示。

## 15. 非功能要求

- 主流程弱网下不丢编辑中的草稿。
- 异步任务状态可恢复，可重试错误保留最后错误和尝试次数。
- 日志不记录密钥、完整正文和不必要的隐私字段。
- 所有查询按租户和用户隔离，媒体使用短期签名 URL 或受控访问。
- 核心点击目标满足微信小程序可触达性和读屏/语义标签要求。
