# 产品需求

## 产品定位

芽芽星球工作台是服务母婴内容创作者的内容生产工具，帮助用户找到值得拍的内容、看懂对标内容、生成符合本人经历和口吻的脚本，并完成拍摄准备。

## 用户目标

- 快速找到适合自己阶段、方向和表达能力的选题。
- 把平台内容沉淀为可搜索、可追溯、可二创的对标资产。
- 看懂内容的钩子、结构、学习点、逐字稿和风险。
- 生成与唯一来源绑定的脚本，避免模板感和跨题串稿。
- 在编辑、换开头、撤销和提词之间连续工作。
- 针对创作问题获得课程、案例、清单和工具。

## 导航与模块

底部导航顺序固定为：首页、创作、对标、成长、我的。

| 模块 | 核心能力 |
| --- | --- |
| 首页 | 今日选题、采集主入口、工具入口、创作进度 |
| 创作 | 选题、方向、口吻、开头、脚本编辑、提词器 |
| 对标 | 采集任务、来源筛选、结构拆解、逐字稿、转创作 |
| 成长 | 问题标签、搜索、课程、案例、清单、工具 |
| 我的 | 创作者资料、平台账号、隐私和设置 |

## 核心业务规则

1. 草稿必须绑定 `sourceType + sourceId`，生成只读取当前来源。
2. 缺字段时返回明确错误，禁止读取其他选题或对标内容兜底。
3. “换一组开头”每次返回三个新选项，选择后才替换，并支持单步撤销。
4. `user_capture`、`yaya_pick`、`legacy_snapshot` 三类来源必须隔离展示。
5. 每次正常采集生成独立 ID；相同幂等键的重放请求返回原资源。
6. 指标必须带采集时间，不得把历史指标表达为实时值。
7. 医疗高风险选题只允许记录、观察和就医沟通框架，不提供诊断、剂量和用药建议。

## 正式数据与服务

- PostgreSQL 是业务数据真源。
- 对象存储保存媒体、封面、原始快照和大文本。
- 采集、转写和分析通过队列与 Worker 异步执行。
- 飞书只作为运营导入导出和后台兼容渠道。
- Prompt、模型、逐字稿和分析结果全部版本化。

## 非功能要求

- Android 与 iOS 使用 Flutter 统一实现，核心页面适配 360–480dp。
- 所有触控目标不小于 44dp，支持系统字号和读屏标签。
- 弱网不丢草稿，任务状态可恢复，可重试错误保留最后错误和尝试次数。
- Token 存储在系统安全区，日志不记录密钥、完整正文和隐私字段。
- 所有查询按租户和用户隔离，媒体使用短期签名 URL。
