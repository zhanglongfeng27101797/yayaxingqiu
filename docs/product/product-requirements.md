# 产品需求｜微信小程序 V1

> 本文只描述产品要做什么。技术实现由研发自行拆解。
>
> 更完整的全量交接见：`docs/handoff/01-完整产品需求.md`。

## 1. 产品定位

芽芽星球工作台是服务公司签约宝妈创作者的 **微信小程序创作工作台**，帮助用户完成：

**今天拍什么 → 找/采集对标 → 看懂爆款 → 变成自己的版本 → 生成脚本 → 提词拍摄 → 学习提升。**

产品不是陪跑服务平台，不提供“专属运营老师 / 陪跑老师 / 联系运营”等服务心智。

## 2. 固定底部导航

**首页｜创作｜对标｜成长｜我的**

- 对标第 3 位
- 成长第 4 位（倒数第二）
- 我的最后

旧“首页｜创作｜成长｜对标｜我的”顺序废弃。

## 3. 首页

### 今天值得拍

- 主推荐 1 条 + 另外 2 条
- 星级
- 为什么推荐给你
- 标签
- 拍摄难度
- 【我想拍】

推荐理由尽量体现“为什么适合这个用户”。

禁止“万人想拍”“XX 人正在拍”等来源不明数据。

### 本月创作简报

可展示：

- 本月发布数
- 累计点赞
- 连续创作天数

正式数据不可得时不伪造。

### 常用工具

首页不放永久链接输入框；点击工具后再输入。

首页高识别工具视觉顺序：

1. 采集爆款
2. 视频拆解（拆视频）
3. 去水印
4. 提词器

同时保留：

- 提取逐字稿
- 灵感库

### 继续创作

展示最近 1–3 条稿件，可继续编辑或去提词。

### 商学苑推荐

推荐 1 条课程 / 分享 / 回放 / 运营精选等内容。

## 4. 创作

### 选题

包含推荐选题、选题列表和选题详情。

详情至少包含：

- 星级
- 推荐理由
- 内容类型
- 宝妈可创作性
- 创作空间
- 拍摄难度
- 内容拥挤度
- 医疗风险
- 平台风险

### 三星选题

三星题不直接淘汰，可提供【帮我改成适合宝妈拍】。

三个改造切口：

- 我的真实经历
- 我当时最想知道的问题
- 一个具体生活场景

### 三步选择式创作

1. 方向：推荐 1 个 + 备选 2 个
2. 开头：每次 3 个，可换一组
3. 口吻：自然聊天 / 真实经验 / 清楚专业 / 有点冲突

方向库：

- 判断解惑
- 避坑纠错
- 流程清单
- 对比选择
- 经验复盘
- 好物种草

生成必须满足：

**源内容 × 方向 × 选中的开头 × 口吻 = 最终稿。**

禁止万能正文、跨稿串稿。

### 脚本编辑

至少包含：

- 标题
- 开头
- 正文
- 结尾
- 拍摄建议

快速优化：

- 更口语
- 再短一点
- 更抓人

换开头：先给 3 个新开头，用户选择后再替换。

建议支持一次撤销和自动保存。

### 我的创作

“我的创作”是统一稿件资产库，统一收纳：

- 首页推荐生成稿
- 创作选题生成稿
- 对标二创稿
- 后续自定义稿

可从“创作”和“我的”进入同一份稿件库，不做两套。

## 5. 提词器

V1 只做小程序内基础提词器：

- 开始 / 暂停
- 慢 / 中 / 快三档速度
- 字号
- 重置
- 镜像开关

不做跨 App 悬浮、专业相机、美颜、滤镜、剪辑。

## 6. 对标

### 列表

- 顶部采集入口
- 全部
- 我的采集
- 芽芽精选

“我的采集”只放用户自己粘贴链接采集的内容；历史迁移内容不混入。

连续采集不能覆盖。

对标卡保持高密度，一屏尽量多条，至少包含：

- 封面
- 星级 / 推荐等级
- 标题
- 内容类型
- 播放（能获得时）
- 点赞
- 收藏
- 评论
- 来源
- 1–2 个值得学标签

### 拆解详情

至少包含：

1. 一句话看懂
2. 为什么值得学
3. 开头为什么抓人
4. 内容结构
5. 最值得学的 3 个地方
6. 逐字稿节选
7. 展开全文
8. 二创提醒
9. 【变成我的版本】

“变成我的版本”继续走方向 → 开头 → 口吻 → 脚本，不做黑盒一键改写。

### 提取逐字稿

链接 → 处理中 → 标题 / 作者 / 逐字稿 → 复制全文 / 保存 / 去拆解。

### 视频拆解

是独立分析动作，可粘贴链接或选择“我的采集”，不能等同于打开对标库。

## 7. 成长｜芽芽星球商学苑

成长位于 TabBar 第 4 位、倒数第二。

主标题固定：**芽芽星球商学苑**。

五个当前问题：

- 不知道拍什么
- 不会写脚本
- 不会拍视频
- 流量起不来
- 想开始带货

商学苑不只放课程，还包括：

- 系统课程
- 内部分享
- 直播回放
- 运营精选
- 爆款复盘
- 平台规则
- 带货经验
- 工具教程

不做：

- 作业
- 打卡 / 签到
- 积分
- 排行榜
- 强制 Level 评级
- 专属运营老师
- 陪跑老师

可以根据用户阶段和资料做轻量内容推荐，但不强制公开评级。

## 8. 我的

建议包含：

1. 用户基本信息
2. 我的创作入口
3. 账号管理 / 添加账号
4. 创作资料
5. 我的权益
6. 消息与通知
7. 帮助与反馈
8. 设置
9. 关于

创作资料至少包括：

- 昵称
- 创作方向
- 宝宝年龄
- 表达风格
- 是否愿意露脸

V1 的账号管理只要求基础信息 / 添加入口，不等于必须完成抖音深度 OAuth 或创作中心深层数据。

用户端不显示“项目负责人：隆隆老师”，不出现“阿欣老师”、运营老师、陪跑老师入口。

## 9. 数据与 Demo 标识

页面 Demo 的业务数据统一标：

**演示版·示例数据**

历史数据标来源与采集时间。

正式数据拿不到时宁可隐藏 / 暂无 / 待绑定，也不要伪造成实时数据。

## 10. 视觉要求

- 70% 温和陪伴 + 30% 专业工作台
- 工具图标醒目统一，避免大量 Emoji
- 主动作 > 高频工具 > 次级功能
- 首页不要做成工具堆叠
- 对标列表保持高密度
- 可参考轻抖类工具产品“入口识别强”的感觉，但不照搬

## 11. V1 不做 / 后续再探索

当前不作为第一版主任务：

- 跨 App 悬浮提词
- 相机 / 美颜 / 滤镜 / 剪辑
- AI 开放式聊天主流程
- 作业 / 打卡 / 等级
- 陪跑服务
- 商城
- 创作中心 5 秒完播等深层指标
- 跨平台账号深度同步
- 复杂推荐和复杂筛选

后续能力池继续保留：

- 浏览器采集助手
- 抖音解析失败时浏览器辅助通道
- 更完整平台数据绑定
- 更完整灵感库
- 更强运营后台

## 12. 三条核心验收链路

### A｜今天不知道拍什么

首页 → 今天值得拍 → 我想拍 → 方向 → 新的 3 个开头 → 口吻 → 正确脚本 → 编辑 → 提词。

### B｜刷到一个爆款

采集爆款 → 我的采集 → 拆解 → 逐字稿 → 变成我的版本 → 方向 / 开头 / 口吻 → 脚本 → 我的创作。

### C｜我想学习

成长 → 芽芽星球商学苑 → 选择当前问题 → 推荐变化 → 课程 / 分享 / 回放 / 运营精选。
