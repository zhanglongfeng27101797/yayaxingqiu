# 产品需求摘要｜微信小程序 V1

> 只描述产品要做什么。完整需求见 `docs/handoff/01-完整产品需求.md`。

## 1. 产品定位

芽芽星球工作台是给公司签约宝妈创作者使用的 **微信小程序创作工作台**。

核心闭环：

**今天拍什么 → 找/采集对标 → 看懂爆款 → 变成自己的版本 → 生成脚本 → 提词拍摄 → 学习提升。**

## 2. 固定底部导航

**首页｜创作｜对标｜成长｜我的**

- 对标第 3
- 成长第 4（倒数第二）
- 我的最后

## 3. 首页

从上到下建议：

1. 顶部问候
2. 今天值得拍
3. 本月创作简报
4. 常用工具
5. 继续创作
6. 商学苑推荐

### 今天值得拍

- 主推荐 1 条 + 另外 2 条
- 星级
- 为什么推荐给你
- 标签
- 拍摄难度
- 【我想拍】

不要“万人想拍”“XX 人正在拍”等来源不明数据。

### 常用工具

首页不放永久链接输入框，点击工具后再输入。

首页高识别工具视觉顺序：

1. 采集爆款
2. 视频拆解（拆视频）
3. 去水印
4. 提词器

同时保留：提取逐字稿、灵感库。

## 4. 创作

### 选题

详情至少包含：

- 星级
- 推荐理由
- 内容类型
- 宝妈可创作性
- 创作空间
- 拍摄难度
- 内容拥挤度
- 医疗风险
- 平台风险

三星题不直接淘汰，可提供【帮我改成适合宝妈拍】。

### 三步选择式创作

1. 方向：推荐 1 个 + 备选 2 个
2. 开头：每次 3 个，可换一组
3. 口吻：自然聊天 / 真实经验 / 清楚专业 / 有点冲突

方向库：判断解惑、避坑纠错、流程清单、对比选择、经验复盘、好物种草。

最终稿必须真实受到：

**源内容 × 方向 × 选中的开头 × 口吻**影响。

禁止万能正文、串稿、换一组只重排。

### 脚本编辑

包含：标题、开头、正文、结尾、拍摄建议。

支持：更口语、再短一点、更抓人、换个开头三选一、一次撤销、自动保存。

### 我的创作

是统一稿件资产库，统一收纳：

- 首页推荐生成稿
- 创作选题生成稿
- 对标二创稿
- 后续自定义稿

可从“创作”和“我的”进入同一份稿件库，不做两套。

## 5. 提词器

V1 只做小程序内基础提词器：

- 开始 / 暂停
- 慢 / 中 / 快三档速度
- 字号
- 重置
- 镜像开关

不做跨 App 悬浮、专业相机、美颜、滤镜、剪辑。

## 6. 对标

### 列表

- 顶部采集入口
- 全部
- 我的采集
- 芽芽精选

“我的采集”只放用户自己采集的内容；历史迁移内容不混入。

连续采集不能覆盖。

对标卡保持高密度，一屏尽量多条，至少包含：

- 封面
- 星级 / 推荐等级
- 标题
- 内容类型
- 播放（能获得时）
- 点赞
- 收藏
- 评论
- 来源
- 1–2 个值得学标签

### 拆解详情

至少包含：

1. 一句话看懂
2. 为什么值得学
3. 开头为什么抓人
4. 内容结构
5. 最值得学的 3 个地方
6. 逐字稿节选
7. 展开全文
8. 二创提醒
9. 【变成我的版本】

“变成我的版本”继续走方向 → 开头 → 口吻 → 脚本。

### 提取逐字稿

链接 → 处理中 → 标题 / 作者 / 逐字稿 → 复制全文 / 保存 / 去拆解。

### 视频拆解

是独立分析动作，可粘贴链接或选择“我的采集”，不能等同于打开对标库。

## 7. 成长｜芽芽星球商学苑

成长位于第 4 位、倒数第二。

主标题固定：**芽芽星球商学苑**。

当前问题：

- 不知道拍什么
- 不会写脚本
- 不会拍视频
- 流量起不来
- 想开始带货

内容不仅是课程，还包括：

- 系统课程
- 内部分享
- 直播回放
- 运营精选
- 爆款复盘
- 平台规则
- 带货经验
- 工具教程

不做作业、签到、积分、排行榜和强制 Level 评级。

可根据用户资料做轻量推荐，但不做公开强制评级。

## 8. 我的

建议包含：

1. 用户基本信息
2. 我的创作入口
3. 账号管理 / 添加账号
4. 创作资料
5. 我的权益
6. 消息与通知
7. 帮助与反馈
8. 设置
9. 关于

创作资料至少包括：昵称、创作方向、宝宝年龄、表达风格、是否愿意露脸。

V1 的账号管理只要求基础信息 / 添加入口，不等于必须完成抖音深度 OAuth 或创作中心深层指标。

## 9. 数据与 Demo

Demo 里的业务数据统一标：**演示版·示例数据**。

历史数据标来源与采集时间。

正式数据拿不到时宁可隐藏 / 暂无 / 待绑定，也不要伪造成实时数据。

## 10. 视觉

- 70% 温和陪伴 + 30% 专业工作台
- 工具图标醒目统一，避免大量 Emoji
- 主动作 > 高频工具 > 次级功能
- 首页不要做成工具堆叠
- 对标列表保持高密度

## 11. 当前不做 / 后续

当前不作为 V1 主任务：跨 App 悬浮提词、相机、美颜、滤镜、剪辑、开放式 AI 聊天主流程、作业打卡等级、商城、创作中心深层指标、复杂推荐、复杂筛选。

后续能力池继续保留：浏览器采集助手、抖音解析失败时浏览器辅助通道、更完整平台数据绑定、更完整灵感库、更强运营后台。
