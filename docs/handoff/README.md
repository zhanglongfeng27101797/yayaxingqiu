## 一句话产品定义

芽芽星球工作台是给公司签约宝妈创作者使用的微信小程序创作助手，核心闭环：

**今天拍什么 → 找/采集对标 → 看懂爆款 → 变成自己的版本 → 生成脚本 → 提词拍摄 → 学习提升。**

## 交接原则

- 旧 Flutter / Android / APK / WebView 代码只能做历史参考。
- 产品需求以本目录和 `docs/product/` 当前文件为准。
- 技术实现方式由公司研发拆解，不由产品侧强行指定。
- 技术上若存在限制，需要回到产品一起调整，不能研发自行改变核心流程。
