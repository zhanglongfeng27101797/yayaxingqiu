## 一句话产品定义

**芽芽星球工作台**是给公司签约宝妈创作者使用的微信小程序创作助手，核心帮助她完成：

**今天拍什么 → 找/采集对标 → 看懂爆款 → 变成自己的版本 → 生成脚本 → 提词拍摄 → 学习提升。**

## 固定底部导航

**首页｜创作｜对标｜成长｜我的**

- 对标第 3 位
- 成长第 4 位，也就是倒数第二
- 我的最后

## 研发理解原则

- 不需要根据历史 Flutter / APK / WebView 代码推导需求。
- 不需要照搬旧 Demo 里的错误交互。
- 不需要产品侧替研发规定数据库、框架、接口实现方式。
- 只要最终页面和功能满足这套产品需求即可。
- 技术上若有实现限制，研发提出后再一起调整，但不能自行改变产品核心逻辑。
