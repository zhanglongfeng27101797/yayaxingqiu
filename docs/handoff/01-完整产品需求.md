# 芽芽星球工作台｜完整产品需求

> 这份文件只回答：**我们到底想做一个什么样的微信小程序。**
>
> 不规定前端框架、后端框架、数据库、接口写法、部署方式。研发可自行拆解技术实现，但不能改变已经确认的产品逻辑。

---

# 0. 项目背景

芽芽星球是公司面向宝妈创作者的 MCN / 创作者体系，芽芽星球工作台服务于**公司签约宝妈创作者**。

目标不是做一个面向所有人的通用工具箱，而是让签约创作者每天更容易完成内容生产：

**今天拍什么 → 找/采集对标 → 看懂爆款 → 变成自己的版本 → 生成脚本 → 提词拍摄 → 学习提升。**

正式产品形态：**微信小程序**。

---

# 1. 产品定位

## 1.1 是什么

一个给签约宝妈用的**创作助手 / 工作台**。

解决：

- 不知道今天拍什么；
- 刷到爆款不会保存、拆解、二创；
- AI 写出来不像自己；
- 写完稿还不知道怎么直接进入拍摄；
- 不知道当前应该学什么。

## 1.2 不是什么

不是陪跑服务平台。

用户端明确不出现：

- 专属运营老师；
- 陪跑老师；
- 联系运营；
- 陪跑服务；
- “阿欣老师”相关入口或文案。

项目内部负责人是隆隆老师，但**不把“项目负责人：隆隆老师”做成普通用户端服务入口**。

## 1.3 AI 交互原则

不以开放式 AI 聊天作为主流程。

主交互是：

**系统推荐 + 用户少量选择。**

不要让普通宝妈面对空白聊天框自己写 Prompt。

---

# 2. 整体产品感觉

- 70% 温和、轻松、陪伴感；
- 30% 专业、效率、工作台感。

不能：

- 太幼稚；
- 太像玩具；
- 太像单纯工具箱；
- 大量用 Emoji 充当正式功能图标。

工具图标要醒目、统一、有识别度，可参考“轻抖”一类工具产品入口清晰的感觉，但不照搬视觉。

---

# 3. 固定底部导航

唯一正确顺序：

**首页｜创作｜对标｜成长｜我的**

位置固定：

1. 首页
2. 创作
3. 对标
4. 成长（倒数第二）
5. 我的（最后）

任何旧文档 / 旧 Demo 中“首页｜创作｜成长｜对标｜我的”都视为历史错误。

---

# 4. 首页 HOME

首页核心不是展示“我们有多少工具”，而是回答：

**我现在该干什么。**

建议从上到下：

1. 顶部问候
2. 今天值得拍
3. 本月创作简报
4. 常用工具
5. 继续创作
6. 商学苑推荐

## 4.1 顶部问候

示例：

- 晚上好，小雨妈妈；
- 芽芽一句轻提示。

不出现客服 / 运营 / 陪跑老师入口。

## 4.2 今天值得拍

首页最重要模块之一。

主推荐 1 条，至少包含：

- 标题；
- 5 星体系；
- 为什么推荐给你；
- 2–3 个标签；
- 拍摄难度；
- 【我想拍】。

主卡下方再展示 2 条更轻量的推荐选题。

“为什么推荐”尽量针对当前用户，例如：

> 这个问题很多新手妈妈都会搜，而且你现在宝宝 8 个月，这类判断型内容比较适合你讲。

禁止：

- “万人想拍”；
- “XX 人正在拍”；
- 来源不明的伪精确匹配度。

## 4.3 本月创作简报

可展示：

- 本月发布数；
- 本月累计点赞；
- 连续创作天数。

正式数据暂不可得时：

- 不伪造实时数据；
- 可隐藏；
- 可显示“待绑定 / 暂无数据”；
- 页面 Demo 可标“演示版·示例数据”。

V1 不要求接入创作中心深层指标，例如 5 秒完播等。

## 4.4 常用工具

首页**不放永久链接输入框**，点击工具后再弹层 / 进入页面输入。

### 首页视觉优先顺序

此前已确认：

1. **采集爆款**
2. **视频拆解（拆视频）**
3. **去水印**
4. **提词器**

同时保留：

- 提取逐字稿；
- 灵感库。

说明：**首页视觉优先级 ≠ 研发实现优先级。**即使某个能力暂时后置，也不能因为技术尚未做完就把产品需求删掉。

### 采集爆款

- 首页高优先级入口；
- 点击后再粘贴链接；
- 成功后可：
  - 留在我的采集；
  - 查看拆解；
  - 进入“变成我的版本”。

### 视频拆解

是一次独立分析动作，不是“打开对标库”。

入口后可：

- 粘贴视频链接；
- 或从“我的采集”选择一条。

分析完成后进入爆款拆解详情。

### 去水印

属于用户明确希望保留的高频工具入口。

如果阶段内真实能力还没做完，可明确“暂未开放 / 建设中”，但不要把入口和需求删掉。

### 提词器

优先读取最近一篇稿件进入提词。

### 提取逐字稿

流程：

粘贴链接 → 处理中 → 标题 / 作者 / 逐字稿 → 复制全文 / 保存 / 去拆解。

### 灵感库

保留产品入口，后续逐步完善。

## 4.5 继续创作

首页显示最近 1–3 条稿件。

每条至少有：

- 标题；
- 来源；
- 更新时间；
- 【继续编辑】；
- 【去提词】。

## 4.6 商学苑推荐

首页可推荐 1 条学习内容。

内容不限定为课程，可以是：

- 课程；
- 分享；
- 直播回放；
- 运营精选；
- 平台规则；
- 工具教程。

# 5. 创作 CREATION

创作模块核心不是“一键 AI 写稿”，而是让用户轻量控制：

**讲什么 → 怎么讲 → 怎么开头 → 用什么口吻讲。**

## 5.1 创作首页

包含：

- 推荐选题；
- 选题列表；
- 搜索 / 基础筛选（如果展示，必须真实可用）；
- 我的创作入口。

选题卡建议包含：

- 标题；
- 星级；
- 内容类型；
- 推荐理由一句；
- 难度；
- 医疗风险（如适用）。

## 5.2 选题详情

至少展示：

- 标题；
- 星级；
- 为什么推荐；
- 内容类型 / 标签；
- 宝妈可创作性；
- 创作空间；
- 拍摄难度；
- 内容拥挤度；
- 医疗风险；
- 平台风险；
- 拍摄建议；
- 【我想拍】。

这些指标不能所有选题都用同一组固定值。

## 5.3 三星选题

三星不是直接淘汰。

如果一个题：

- 有需求；
- 但太专业 / 太泛 / 普通宝妈不适合直接讲；

可显示：

**★★★☆☆ 可以改**

按钮：

【帮我改成适合宝妈拍】

给三个轻量切口：

1. 我的真实经历
2. 我当时最想知道的问题
3. 一个具体生活场景

然后进入正常创作流程。

## 5.4 三步选择式创作

### Step 1｜这条想怎么讲

默认显示 3 个：

- 推荐 1 个；
- 备选 2 个。

方向库：

- 判断解惑；
- 避坑纠错；
- 流程清单；
- 对比选择；
- 经验复盘；
- 好物种草。

如果展示【查看更多方式】，必须真的能展开；否则不放假按钮。

### Step 2｜你更喜欢哪个开头

每次给 3 个开头。

点击【换一组】后必须出现新的 3 个开头。

不能只是：

A / B / C → B / C / A。

### Step 3｜你想怎么说

四种口吻：

- 自然聊天；
- 真实经验；
- 清楚专业；
- 有点冲突。

## 5.5 生成逻辑

最终脚本必须满足：

**源内容 × 内容方向 × 选中的开头 × 表达口吻 = 最终稿。**

- 选题决定讲什么；
- 方向决定怎么组织；
- 开头决定前 3 秒怎么说；
- 口吻决定怎么表达。

禁止：

- 不同选题共用万能正文；
- 当前稿缺字段时读取另一条稿件正文兜底；
- 用户选择变化但结果不变。

## 5.6 脚本编辑

至少包含：

- 标题；
- 开头；
- 正文；
- 结尾；
- 拍摄建议。

用户可直接编辑。

快速优化：

- 更口语；
- 再短一点；
- 更抓人。

优化后建议提供一次【撤销】。

### 换个开头

正确方式：

点击【换个开头】 → 弹出 3 个新开头 → 用户选择 → 再替换。

不能直接偷偷覆盖原开头。

## 5.7 我的创作

“我的创作”是**统一稿件 / 草稿资产库**，不是另一套创作逻辑。

统一收纳：

- 首页推荐选题生成稿；
- 创作页选题生成稿；
- 对标二创稿；
- 后续自定义选题稿。

同一份“我的创作”可从：

- 创作页进入；
- 我的页进入。

两个入口必须指向同一个稿件库，不做两套。

每条至少可：

- 继续编辑；
- 去提词。

## 5.8 自动保存

脚本编辑过程中需要有保存状态，避免退出后丢稿。

---

# 6. 小程序内提词器

V1 只做基础提词器。

必须有：

- 开始 / 暂停；
- 慢 / 中 / 快三档速度；
- 字号调整；
- 重置；
- 镜像开关（建议保留）。

切换速度后要真实影响滚动。

明确不做：

- 跨 App 悬浮；
- 系统级悬浮窗；
- 小程序内专业相机；
- 美颜；
- 滤镜；
- 剪辑。

---

# 7. 对标 BENCHMARK

对标不是普通收藏夹，而是：

**研究爆款 + 变成自己的内容。**

## 7.1 顶部入口

保留明显的【粘贴链接采集】入口，但不要占满整个页面。

## 7.2 列表分类

至少：

- 全部；
- 我的采集；
- 芽芽精选。

来源含义：

- 我的采集 = 用户自己粘贴链接采集；
- 芽芽精选 = 公司 / 运营精选；
- 历史迁移内容 = 只在“全部”展示并标历史来源。

不能把历史采集表内容混进“我的采集”。

## 7.3 连续采集

用户连续采集 3 条，必须保留 3 条，不能后一条覆盖前一条。

## 7.4 对标卡片

要求高密度，一屏尽量多条。

至少包含：

- 封面；
- 星级 / 推荐等级；
- 标题；
- 内容类型；
- 播放（能获得时）；
- 点赞；
- 收藏；
- 评论；
- 来源；
- 1–2 个“值得学”标签；
- 拆解入口。

禁止：

- 来源不明的“XX 人想拍”；
- 伪精确匹配度。

## 7.5 爆款拆解详情

页面建议顺序：

1. 封面 / 标题 / 作者 / 数据 / 星级
2. 一句话看懂这条
3. 为什么值得学
4. 开头为什么抓人
5. 内容结构
6. 最值得学的 3 个地方
7. 逐字稿节选
8. 展开全文
9. 二创提醒
10. 【变成我的版本】

## 7.6 逐字稿

对标详情必须有逐字稿。

默认可先显示节选，点击再展开全文。

## 7.7 变成我的版本

点击后继续复用创作设置：

方向 → 3 个开头 → 口吻 → 生成脚本 → 自动进入“我的创作”。

不做一键黑盒改写。

# 8. 成长 GROWTH

位置：**第 4 个 Tab，倒数第二。**

主标题固定：

**芽芽星球商学苑**

成长不是课程商城，也不是训练营作业中心。

未来公司可以持续上架课程和其他分享内容，不局限固定课程。

## 8.1 你现在最想解决什么

五个问题全部可见，可两行自动换行：

- 不知道拍什么；
- 不会写脚本；
- 不会拍视频；
- 流量起不来；
- 想开始带货。

## 8.2 为你推荐

根据用户当前问题推荐 1 条内容。

内容可以是：

- 系统课程；
- 内部分享；
- 直播回放；
- 运营精选；
- 爆款复盘；
- 平台规则；
- 带货经验；
- 工具教程。

## 8.3 页面内容结构

建议包含：

- 为你推荐；
- 系统课程；
- 本周分享 / 直播回放；
- 运营精选；
- 最新内容。

不要只做成课程列表。

## 8.4 用户阶段

不做强制公开评级。

可以在系统内部根据：

- 用户阶段；
- 创作资料；
- 当前问题；

做轻量推荐，但不要向用户展示：

- Level 1 / Level 2；
- 强制升级；
- 新手等级考核。

## 8.5 明确禁止

- 作业；
- 打卡 / 签到；
- 积分；
- 排行榜；
- 强制评级；
- 专属运营老师；
- 陪跑老师；
- 联系运营。

---

# 9. 我的 PROFILE

“我的”是账号、创作资料、内容资产和基础设置集合。

建议包含：

1. 用户基本信息
2. 我的创作入口（统一稿件库）
3. 账号管理 / 添加账号
4. 创作资料
5. 我的权益
6. 消息与通知
7. 帮助与反馈
8. 设置
9. 关于

## 9.1 创作资料

至少可编辑：

- 昵称；
- 创作方向；
- 宝宝年龄；
- 表达风格；
- 是否愿意露脸。

保存后真实回写。

## 9.2 账号管理

V1 先做基础账号信息和添加入口即可。

不代表 V1 必须完成：

- 抖音深度 OAuth；
- 创作中心完整数据同步；
- 5 秒完播等深层指标。

这些后续再探索。

## 9.3 用户端不显示内部负责人

不要展示：

- 项目负责人：隆隆老师；
- 阿欣老师；
- 联系运营老师。

---

# 10. 页面数据与 Demo 标识

页面 Demo 里的业务数据，如：

- 粉丝；
- 播放；
- 点赞；
- 收藏；
- 评论；
- 发布数；
- 增长数据；

统一明确标：

**演示版·示例数据**

或标明：

**历史快照 + 采集时间。**

正式数据不可得时，宁可隐藏 / 暂无 / 待绑定，也不要伪造成实时数据。

---

# 11. 搜索与假交互

创作、成长等页面如果展示搜索框，就必须至少支持最基本关键词过滤。

如果阶段内不做，就先不要画成一个完全可输入但无反馈的正式搜索框。

同样适用于：

- 收藏；
- 筛选；
- 查看更多；
- 换一组。

核心原则：

**能看到、能点、属于主流程的功能，就必须有真实意义。**

---

# 12. 视觉与信息密度

## 12.1 整体风格

- 温和；
- 轻量；
- 清晰；
- 不过度粉幼；
- 有明显工作台效率感。

## 12.2 图标

- 工具图标醒目统一；
- 不大量使用 Emoji；
- 功能入口高识别。

## 12.3 信息密度

- 首页主动作突出；
- 对标列表一屏多条；
- 不要所有模块都做成同样权重的大卡；
- 主 CTA > 高频工具 > 次级功能。

---

# 13. 当前不做 / 后续再探索

## 当前不作为第一版主任务

- 跨 App 悬浮提词；
- 专业相机；
- 美颜 / 滤镜 / 视频剪辑；
- AI 开放式聊天主流程；
- 作业 / 打卡 / 积分 / 排行榜 / 等级；
- 陪跑服务；
- 专属运营老师；
- 商城；
- 创作中心 5 秒完播等深层指标；
- 跨平台账号深度同步；
- 复杂推荐系统；
- 复杂筛选。

## 后续能力池继续保留

- 浏览器采集助手；
- 抖音解析失败时浏览器辅助通道；
- 更完整的平台数据绑定；
- 更完整灵感库；
- 更强运营后台；
- 更丰富的商学苑内容。

# 14. 三条最重要验收链路

## A｜今天不知道拍什么

首页 → 今天值得拍 → 我想拍 → 方向 → 新的 3 个开头 → 口吻 → 生成正确脚本 → 编辑 → 提词 → 调速度并开始。

失败红线：

- 串稿；
- 选方向 / 口吻结果不变；
- 换一组只是重排；
- 提词器速度不生效。

## B｜刷到一个爆款

首页采集爆款 → 粘贴链接 → 采集 → 我的采集 → 拆解 → 看逐字稿 → 变成我的版本 → 方向 / 开头 / 口吻 → 脚本 → 我的创作。

失败红线：

- 连续采集覆盖；
- 我的采集混进历史内容；
- 拆解详情没有逐字稿；
- 视频拆解只是打开对标库。

## C｜我想学习

成长 → 芽芽星球商学苑 → 选择当前问题 → 推荐变化 → 打开课程 / 分享 / 回放 / 运营精选。

失败红线：

- 成长变成单纯课程商城；
- 出现作业 / 评级 / 陪跑老师。

# 15. 已明确纠正、绝对不要做回去

1. 底栏不能再做成：首页｜创作｜成长｜对标｜我的。
2. 正确顺序：首页｜创作｜对标｜成长｜我的。
3. 成长必须倒数第二。
4. 首页不放永久采集输入框。
5. 不出现“万人想拍”等无真实来源数据。
6. 不出现专属运营老师 / 陪跑老师。
7. 不出现阿欣老师。
8. 不把隆隆老师做成用户端服务入口。
9. 不把成长做成作业中心。
10. 不把成长只做成课程商城。
11. 不把视频拆解等同于打开对标库。
12. 不把“换一组开头”做成原 3 句换顺序。
13. 不用万能正文套所有选题。
14. 不允许不同草稿互相串正文。
15. 不允许连续采集覆盖上一条。
16. “我的采集”不能混入历史采集表。
17. 爆款拆解必须包含逐字稿。
18. 提词器速度必须真的能调。
19. “我的创作”必须是统一稿件资产库，不做两套草稿系统。
20. 旧 APK / Flutter / WebView Demo 只参考视觉和早期交互，不反向覆盖这份需求。

# 16. 最终理解

研发不需要照产品侧指定的代码框架写。

最终只要保证一个签约宝妈打开后：

- 知道今天拍什么；
- 刷到好内容能采集和拆；
- 能把别人的爆款变成自己的脚本；
- 脚本不是万能模板；
- 写完能直接进入提词；
- 遇到问题能去商学苑学习。

这就是芽芽星球工作台的核心。
