# 来源与架构决策

## 产品来源

- V1.0 交接资料提供产品定位、五大模块、核心闭环和初始数据结构。
- V1.1 修改方案补充导航顺序、生成真实性、开头换组、串稿隔离、转写、拆解、来源筛选、成长和资料保存。
- V1.2 进一步明确 PostgreSQL、对象存储、异步任务、API、错误码、医疗安全、隐私、迁移和验收。

## 当前工程决策

- 移动端统一使用 Flutter/Dart，实现 Android 与 iOS。
- 服务端、BFF、任务 Worker 和共享契约使用 TypeScript。
- PostgreSQL 是业务真源，对象存储保存媒体和大文本。
- 飞书只用于运营导入导出，不作为移动端在线数据库。
- 原育咖采集表按 `legacy_snapshot` 迁移，保留来源和采集时间，不混入用户采集与运营精选。
- 生成服务只读取唯一来源，禁止跨选题或对标内容兜底。

## 冲突裁决顺序

`当前 Dart/TypeScript 架构决策 > V1.2 产品规则 > V1.1 修改方案 > V1.0 初始资料`
