# 测试、发布与验收

## 移动端 P0

- [ ] 首页、创作、对标、成长、我的顺序固定，入口均可达。
- [ ] 选题切换方向和口吻后，生成结果有明显差异。
- [ ] 新开头每组返回三个不同选项，应用后支持单步撤销。
- [ ] 缺少来源字段时明确失败，不出现跨题正文。
- [ ] 提词器慢/中/快三档、字号、镜像和重置正常。
- [ ] 采集、逐字稿和分析展示真实远程任务状态。
- [ ] 高医疗风险内容不输出诊断、剂量和用药建议。
- [ ] 创作者资料保存后跨页面一致，重新启动仍能恢复。

## 服务端 P0

- [ ] 未登录、越权、无数据、弱网、超时和第三方限流均有稳定错误码。
- [ ] 重放同一幂等请求不创建重复任务或草稿。
- [ ] 所有读写按 `tenantId + userId` 隔离。
- [ ] 任务只按合法状态转换，重试保留 attempt 和最后错误。
- [ ] Transcript、Analysis 和 Prompt 保存提供方、模型、版本与创建时间。
- [ ] 日志不包含 Token、完整正文、签名参数和隐私字段。
