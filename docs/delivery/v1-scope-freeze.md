# V1 范围冻结｜微信小程序

> 目的：让产品、前端、后端、测试对“第一版到底做什么、不做什么”有同一答案。

## 1. 正式平台

- 正式交付形态：微信小程序。
- Android APK / Flutter：历史 Demo，仅作视觉与交互参考。
- 第一版不做独立 Android/iOS App。

## 2. P0 必须完成

### 首页

- 固定 TabBar： 首页｜创作｜对标｜成长｜我的
- 今天值得拍
- 采集爆款主入口
- 本月创作简报（正式数据未接时可降级/隐藏）
- 常用工具：采集爆款、逐字稿、视频拆解、提词器
- 继续创作
- 商学苑推荐

### 创作

- 选题列表/搜索
- 选题详情
- 推荐方向 1 + 备选方向 2
- 三个开头
- 换一组开头
- 四种口吻
- 生成脚本
- 脚本编辑
- 换个开头三选一
- 单步撤销
- 自动保存
- 小程序内提词器：慢/中/快、字号、镜像、重置

### 对标

- 粘贴链接采集
- 全部 / 我的采集 / 芽芽精选
- 正确隔离 user_capture / yaya_pick / legacy_snapshot
- 爆款卡
- 拆解详情
- 逐字稿节选/全文
- 变成我的版本
- 连续采集不覆盖

### 成长

- 芽芽星球商学苑
- 当前问题五类
- 动态推荐
- 系统课程
- 分享 / 直播回放
- 运营精选
- 最新内容

### 我的

- 用户基本信息
- 账号绑定入口
- 创作资料编辑与保存
- 权益 / 消息 / 帮助 / 设置 / 关于

### 后端

- 微信登录与业务会话
- CreatorProfile
- Topic
- Benchmark
- Capture Job
- Transcript Job
- Analysis Job
- ScriptDraft
- Academy feed
- PostgreSQL

- Worker 状态机
- 幂等、错误码、租户/用户隔离

## 3. P1 应完成

- 三星选题“帮我改成适合宝妈拍”
- 本地搜索与基础筛选
- 草稿编辑失败恢复
- 内容安全风险提示
- 运营精选管理能力的后端基础
- 商学苑多内容类型管理基础
- 账号绑定信息完善

## 4. P2 后置

- 去水印完整能力
- 灵感库完整能力
- 复杂筛选
- 创作中心深层指标（5 秒完播等）
- 跨平台账号深度绑定
- 复杂推荐系统
- 正式运营后台完整 UI

## 5. 明确不做

- 跨 App 悬浮提词器
- 小程序内自建专业相机
- 美颜 / 滤镜 / 视频剪辑
- AI 开放式聊天作为主交互
- 作业、打卡、积分、排行榜、Level 评级
- 专属运营老师 / 陪跑老师 / 联系运营
- 陪跑服务
- 商城
- 第一版独立 Android/iOS App

## 6. 交付物

前端：

- 可在微信开发者工具运行的正式小程序工程
- 测试环境配置说明
- 页面与组件说明
- P0 真机验收通过

后端：

- API 服务
- 数据库 migration
- Worker/队列基础
- 环境变量模板
- 接口契约 / OpenAPI（建议）
- 测试环境部署说明

产品/测试：

- 页面规格
- 接口/状态矩阵
- P0 验收清单
- 已知限制

## 7. V1 完成定义

V1 不是“页面都画出来”，而是三条链路完整成立：

1. 不知道拍什么 → 得到正确脚本 → 小程序内提词；
2. 刷到爆款 → 采集 → 拆解 → 看逐字稿 → 二创；
3. 遇到创作问题 → 商学苑找到针对性内容。

任一核心流程仍依赖假按钮、固定模板串稿或统一 Toast，则不能标记为 V1 完成。
