# 技术资料说明

本目录里的架构、数据模型、API 等文件是此前阶段形成的**技术草案 / 历史材料**。

当前给公司前端 / 后端的正式交接重点是：

- 完整产品需求
- 页面规格
- 用户流程
- 页面 Demo

**本目录不代表要求公司研发必须采用其中的 Flutter、Fastify、PostgreSQL、Worker、接口结构或其他技术实现。**

研发可在理解产品需求后自行拆解技术方案。

如果本目录任何技术草案与当前产品需求冲突，以：

`docs/handoff/01-完整产品需求.md`

和：

`docs/product/page-specification.md`

为准。
